# GitHub Copilot Path-Scoped Instructions

Generated VS Code Copilot workspace-scoped instruction adapters, one per canonical rule.

## Ownership

- Canonical rule content lives in repo-root `rules/`.
- `github-copilot/instructions/*.instructions.md` is generated by
  `node scripts/sync-canonical-adapters.js`.
- The generator derives `applyTo` from the canonical rule frontmatter (`applyTo` when
  present, otherwise the canonical `paths:` list).

## Install

VS Code Copilot loads instructions from `.github/instructions/` at the workspace root.
Use the installer to wire this directory into a project:

```sh
bash github-copilot/scripts/install.sh --target /path/to/project
```

After running the installer, reload the VS Code window so the instructions are re-read.
